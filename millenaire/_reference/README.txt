Millénaire custom content — reference catalogs
==============================================

This directory is regenerated on every server start. Do not edit
these files — edits are overwritten. Use them as read-only
references when authoring custom content.

Files:
  goals.txt                All registered goal ids (for villager_type.goals)
  gathering_handlers.txt   All registered gathering handler ids
                           (for gathering_type/<id>.json "handler" field)
  special_points.txt       The 9 mock block types usable inside NBT templates

Not yet generated (pending):
  tags.txt                 Building + villager tags. Tags are crowd-sourced
                           from existing JSON files — inspect
                           cultures/norman/ for real examples.

For JSON schema references, inspect the deployed built-in cultures
(cultures/norman/ is the most complete). See docs/feat/custom-content.md
for authoring workflows.
